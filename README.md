# SOC / Blue Team Writeups

Hands-on notes and lab writeups as I build defensive security (SOC Level 1) skills:
log analysis, SIEM, phishing analysis, and threat detection — mapped to **MITRE ATT&CK**
and the **Cyber Kill Chain**.

I come from web development and offensive security (bug bounty on Bugcrowd, OWASP labs).
This repo documents the **Blue Team** side: how a SOC analyst detects, triages, and
escalates what an attacker does.
